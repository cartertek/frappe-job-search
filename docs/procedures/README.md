# Versioned operating procedures

The canonical initial procedure definitions are checked into job_search/setup/procedures.json and loaded as versioned Job Search Procedure records. Never edit the content of an active published version; add a new version to the seed file. Old definitions remain available to interpret historical executions.

The ten initial procedures cover discovery, employer research, opening research, qualification, application preparation, application recording, follow-up, interview preparation, interview outcomes, and closure. Each version has ordered required steps. Operators record findings and outputs for each step; completing a CRM Deal stage alone never completes a procedure.
